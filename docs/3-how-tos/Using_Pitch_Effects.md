
# How to Use Pitch Effects with Mega PCM 2

Mega PCM 2 allows you to easily alter pitch of currently playing sample using `MPCM_setPitch` macro. Gradually changing pitch over time, depending on speed and direction, may achieve a few interesting effects, like "tape stop", "broken record" and others.

In this quick tutorial we'll go over using `MPCM_setPitch` macro in code for a slowdown (tape stop) effect in Sonic 1.

## Sonic 1 Github Disassembly

This quick & dirty example applies low pitch effect to stock SEGA sound in Sonic 1. Provided you followed current [Installation Guide for Sonic 1 Github Disassembly](../1-installation/Sonic-1-Github.md), it should work out of the box.

Open `sonic.asm`, find `Sega_WaitEnd:` and modify code around it as shown in this diff (replace first block, add a new block with pitch effect in `Sega_WaitEnd` loop)

```diff
-               ; while "SEGA" sound is playing
-               move.b  #sfx_Sega,d0                    ; set "SEGA" sound
-               bsr.w   QueueSound2                     ; queue it
-               move.b  #id_VBlank_SegaPCM,(v_vblank_routine).w ; set VBlank routine to $14
-               bsr.w   WaitForVBlank                   ; wait for VBlank to play the sound (CPU is frozen here until sound finished playing)
-; ---------------------------------------------------------------------------
-
-               ; after sound has finished playing
-               move.w  #30+2*60,(v_generictimer).w     ; wait 30 frames before automatic fade-out
+               move.w  #30+2*60,(v_generictimer).w     ; set timer to 2.5 seconds (before automatic fade-out)
+               MPCM_play #dacSega.id                   ; request SEGA sample
+               move.b  #dacSega.pitch, d6              ; d6 = initial pitch
 
 Sega_WaitEnd:
                move.b  #id_VBlank_Sega,(v_vblank_routine).w ; set VBlank routine to $02
                bsr.w   WaitForVBlank                   ; wait for VBlank to finish
+               cmp.w   #80, (v_generictimer).w         ; less than 80 frames left?
+               bhi.s   .pitch_ok                       ; if not, branch
+               subq.b  #2, d6                          ; lower pitch
+               MPCM_setPitch d6                        ; update active sample pitch
+.pitch_ok:
                tst.w   (v_generictimer).w              ; has post-chant timer expired?
                beq.s   Sega_GotoTitle                  ; if yes, go to title screen
                andi.b  #btnStart,(v_jpadpress1).w      ; is Start button pressed?
```

> [!NOTE]
>
> If you used older version of the guide, your sample table may differ and you may not have `dacSega.id` / `dacSega.pitch` defined. In this case, just open you sample table (`SamleTable.asm`) and make sure Sega PCM sample record looks like this (notice the `dacSega:` label):
>
> ```m68k
> dacSega:        dcSample        TYPE_PCM,       SegaVoice,      16000,          FLAGS_SFX       ; $8C
> ```

> [!WARNING]
>
> You need to manually specify Sample rate in sample table for `.pitch` property to become available! While Mega PCM 2 can auto-detect sample rate for .WAV and .DPCMQ files, making Sample rate optional, this unfortunately happens at boot-time, hence why `.pitch` cannot be determined at assembly time.

Let's quickly go over the code changes:

- We replaced `move.b #sfx_Sega,d0 / bsr.w QueueSound2` with `MPCM_play #dacSega.id` just for clarity, because if you followed installation guide, you may notice that SMPS also does `MPCM_play #dacSega.id` when playing `sfx_Sega` under the hood.
- `move.b #dacSega.pitch, d6` saves base sample pitch to register D6 to be used below.
- Finally, if `v_generictimer` is lower than 80 (meaning 80 TV frames remaining before screen fade out), we do `subq.b #2, d6 / MPCM_setPitch d6`. This lowers the pitch each frame and updates it on Mega PCM's side.

> [!WARNING]
>
> Be careful with byte overflows when continuously incrementing/decrementing pitch! Mega PCM supports 256 pitch levels, so `.pitch` is an 8-bit value. If you don't check for overflows, pitch may jump between min/max levels depending on direction.
>
> Also, since base pitch is calculated from Sample rate, it will be different for different samples, so, say, lowering pitch to zero may take longer to apply on high sample rates.


## Other Examples and References

For generic standalone example with slightly more pitch effects, also see [`examples/demo-roms/sample-pitch.asm`](../../examples/demo-roms/sample-pitch.asm). This ROM can be downloaded among other examples from [Mega PCM Releases](https://github.com/vladikcomper/MegaPCM/releases) page (see `example-roms.zip`).

Instead of `MPCM_setPitch` macro you can alternatively use `jsr MegaPCM_SetActiveSamplePitch`, which includes code generated by this macro under the hood, but is less flexible and requires you to pass pitch in `d0`. Please see [Mega PCM 2 API Documentation](../API.md) for reference.
